## Reglas de esta carpeta

1. Las **fuentes oficiales** de arquitectura viven en `00_CORE/`, no aquí.
2. Esta carpeta guarda: historial de decisiones, inventarios, bitácoras de
   sesión (las recientes; rotar), análisis puntuales.
3. Nada de contenido pesado (DOCX, videos, imágenes) — eso va a
   `C:\Users\Carlos\Desktop\ARCHIVO_ADIS\` (ver inventario).
4. Un nuevo documento aquí debe justificar por qué no pertenece al
   `CONTEXTO.md` de un módulo ni a `00_CORE`.
